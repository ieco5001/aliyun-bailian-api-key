## 阿里云百炼开通前要准备什么

准备事项只有两个：阿里云账号，以及实名认证。

## 如果你想用 RAM 子账号开通

这是官方 FAQ 里被问得最多的坑之一：用 RAM 子账号（RAM用户或RAM角色）开通百炼时提示无权限，原因通常是主账号没授权。

主账号需要先在 RAM 控制台给子账号授予 `AliyunBailianFullAccess` 系统策略。注意是这一条系统策略，其他管控层权限组合不行。授权完成后，子账号才能正常走开通流程。

另外，免费试用额度是主账号和它的 RAM 子账号共享的，不用担心子账号调用会「重复领额度」或者两边分开算。

## 创建 API Key 并跑通第一次调用

模型调用需要 API Key 作为身份凭证，创建路径在控制台里：

1. 进入百炼控制台，点击页面右上角的头像图标。
2. 在下拉菜单里选「API-KEY」（新版界面是左侧栏的「API-Key」）。
3. 点「创建」，生成一串 sk 开头的 Key。
4. 复制保存好，后面所有调用都用它。

有了 Key，第一次调用可以用最简单的 HTTP 请求验证。以 DeepSeek-V3 为例（换成通义千问等其他模型，改 `model` 字段即可）：

bash
curl -X POST https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions \
-H "Authorization: Bearer $DASHSCOPE_API_KEY" \
-H "Content-Type: application/json" \
-d '{
    "model": "deepseek-v3",
    "stream": true,
    "messages": [
        {
            "role": "user",
            "content": "9.9和9.11谁大"
        }
    ]
}'


把 `$DASHSCOPE_API_KEY` 换成你的 Key，能正常返回结果就说明开通成功。如果报错，先检查 Key 是否填对，再对照官方错误码文档排查。

不想写代码也行。百炼自带应用构建能力，官方入门教程的第一条路线就是零代码搭建私有知识问答应用：导入你的私有文档，就能生成一个能回答私有领域问题的问答应用，全程不用碰一行代码。

走本地开发路线的话，官方提供 DashScope SDK，支持 Java 和 Python，安装后按文档接入即可。

## 开通后怎么停用？扣费怎么查？

百炼服务目前开通后不支持关闭。这不代表会一直扣钱——费用只来自模型调用，不调用就不产生费用。担心误调用的话，把控制台里已创建的 API-Key 全部删掉即可，没有 Key 就发不起调用。

查扣费明细：前往阿里云「费用与成本」页面，按账期查看扣款项。需要开票的话，在「月账单概览」页面找到目标账号，点「下载发票」。

数据安全方面，官方明确表示不会将用户数据用于模型训练，应用构建和模型训练过程中传输的数据都会经过 AES-256 加密。这点对要接入业务数据的企业用户比较关键。

## 常见问题

**开通百炼要花钱吗？**
开通本身免费，新用户还有免费试用额度。产生费用的只有模型调用，按量计费。

**RAM 子账号开通时提示无权限怎么办？**
让主账号在 RAM 控制台授予 `AliyunBailianFullAccess` 系统策略，其他权限组合无效。

**免费额度多久过期？**
从开通百炼或模型申请通过之日起算，一般30~180天，各模型不同，以模型广场展示为准。

**体验中心的对话记录会一直保留吗？**
控制台最多展示100条历史对话，不设时间限制。未登录状态下的体验对话、推理报错时的对话不会被保存。

**百炼有手机 App 吗？**
没有官方独立手机应用，主要通过 Web 控制台使用。

**百炼和通义千问是什么关系？**
百炼是大模型服务平台，提供包括千问系列在内的多种大模型，千问是平台上的模型之一。
